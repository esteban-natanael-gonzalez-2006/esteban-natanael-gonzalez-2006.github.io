# Project AFT_Ouroboros — Official Portal

This repository hosts the official scientific portal and public documentation for **Project AFT_Ouroboros**:
[https://aft-ouroboros.org](https://aft-ouroboros.org)

## Research Focus
- Non-dissipative recurrent sequence architectures.
- Clifford spinor phase spaces and symplectic geometry.
- Cellular cohomology and topological knot memory crystallization.
- Cache-confined deterministic execution on low-power consumer silicon (Snapdragon 870 / Kryo 585 Prime) and open RISC-V hardware.

## Public Codebases
- [aft-ouroboros-silicon-benchmarks](https://github.com/esteban-natanael-gonzalez-2006/aft-ouroboros-silicon-benchmarks): Reproducibility suite and physical silicon telemetry.
- [AFT-Ouroboros RISC-V Coprocessor](https://github.com/esteban-natanael-gonzalez-2006/AFT-Ouroboros-An-Open-Hardware-Linear-Sequence-Coprocessor-for-Resource-Constrained-RISC-V-SoCs): SystemVerilog RTL definitions.
- [ouroboros-ns-snn](https://github.com/esteban-natanael-gonzalez-2006/ouroboros-ns-snn): Navier-Stokes numerical framework for neuromorphic systems.
